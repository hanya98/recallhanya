# Feature List (MVP + v1.1 + future)

## Tier 0 — Hackathon MVP (24-hour, what we ship)

| #  | Feature                              | Done when a stranger can do it in the demo   |
|----|--------------------------------------|----------------------------------------------|
| 1  | Chrome extension captures pages      | Visit 5 pages, see 5 entries in dashboard    |
| 2  | AI-generated summary per page        | Hover card → see 2-sentence summary          |
| 3  | Semantic search (natural language)    | "react auth" returns 3 non-keyword matches   |
| 4  | Memory timeline (date-grouped)       | Scroll → memories group by day               |
| 5  | Spotlight command bar (Cmd+K)        | Press Cmd+K from anywhere → search overlay   |
| 6  | Memory cards with reopen button      | Click → original tab opens                   |
| 7  | Smart Collections (auto-clustered)   | "AI Research" group shows 8 related memories |
| 8  | Context Resume (reopen all)          | Click "Resume" → 6 tabs reopen               |
| 9  | Sign-in with Google                  | Cold install → logged in → memory persisted  |
| 10 | Pause / delete privacy controls      | Toggle → no new captures                     |

## Tier 1 — Post-hackathon polish (v1.1, 1-2 weeks)

- Memory Graph (force-directed viz)
- Related memories on each card
- Per-collection descriptions generated by LLM
- Better empty states
- Mobile-responsive dashboard
- Email digest: "Yesterday you saw 47 things. Here are the highlights."
- Cross-device sync (signed-in user, multi-machine)

## Tier 2 — v2, sources beyond Chrome

- Gmail connector (read-only, OAuth)
- Google Drive (Docs, PDFs)
- Notion (per-page snapshots)
- VS Code extension (open files)
- Local file watcher (Downloads, Documents)

## Tier 3 — Roadmap (12+ months)

- **OS-wide memory layer.** Native desktop agent (Electron or Tauri). Captures all apps.
- **Mobile (iOS / Android share sheet)** — capture from any app.
- **Proactive AI recommendations.** "You read 6 things about LangGraph last week. Here's a new paper on it."
- **Cross-device sync** with end-to-end encryption.
- **Team plans** — shared memory across an org.
- **API for third parties.**

## Non-goals (for now)

- A full social/multiplayer experience.
- A "second-brain" that writes notes for you.
- An email client.
- A calendar.
- A task manager.
- A chat interface as the primary surface (search is).

## Hard engineering constraints

- **Latency budget for search:** p95 < 400ms end-to-end.
- **Memory weight per snapshot:** < 8KB on average. (Raw HTML not stored.)
- **Capture latency:** extension → queryable in < 3s.
- **Offline:** extension queues captures when offline, flushes on reconnect.
- **No login to use?** No — Google sign-in is required (cloud memory).
