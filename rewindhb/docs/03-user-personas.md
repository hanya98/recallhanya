# User Personas

## Persona 1 — Aarav, the curious engineer
- **Age:** 23 · **Role:** Final-year CS student + part-time intern
- **Stack:** Reads Hacker News, GitHub, Arxiv, docs, dev.to, StackOverflow
- **Daily:** Opens ~30 dev-related tabs/day. Bookmarks maybe 1.
- **Pain point:** *"I keep losing that one repo about auth I saw last Tuesday."*
- **Aha moment:** Spotlight search → "react authentication example" → finds the repo he never bookmarked, with AI summary intact.
- **Key feature:** Semantic search across last 30 days, code-aware.
- **Willingness to pay:** Yes, after a free tier, if he can find an internship email faster.

## Persona 2 — Maya, the senior PM
- **Age:** 31 · **Role:** PM at a Series B startup
- **Stack:** LinkedIn, Substack, Twitter, Notion, competitor sites, user research reports
- **Daily:** ~50 tabs opened. Saves to "Read later" inbox that grows to 200 and never gets read.
- **Pain point:** *"I want to write a PRD about onboarding but I've forgotten every good reference I saw."*
- **Aha moment:** "Show me everything I've seen about onboarding" → returns a Smart Collection of articles, posts, and competitor pages, all summarized.
- **Key feature:** Smart Collections + Context Resume across weeks.

## Persona 3 — Diego, the founder / indie hacker
- **Age:** 28 · **Role:** Solo founder
- **Stack:** Twitter, Product Hunt, IndieHackers, Stripe docs, pricing pages, marketing sites
- **Daily:** 60+ tabs. Jumps between ideas constantly.
- **Pain point:** *"I saw a pricing page I loved three weeks ago and now I need to reference it."*
- **Aha moment:** Timeline → filter by "Pricing pages" → reopens the exact page.
- **Key feature:** Visual timeline + collections by topic.

## Persona 4 — Priya, the PhD researcher
- **Age:** 26 · **Role:** ML PhD
- **Stack:** Arxiv, Google Scholar, Papers With Code, conference videos, blog posts
- **Daily:** Reads 10+ papers, watches 3+ talks, browses 20+ blog posts.
- **Pain point:** *"I'm writing a related-work section and I remember reading something relevant on transformer interpretability but I have no idea which paper."*
- **Aha moment:** "Transformer interpretability" in spotlight → returns a cluster of related papers, posts, and videos, with the AI summary calling out the key concept.
- **Key feature:** Semantic search that bridges papers / blogs / videos / GitHub.

## Persona 5 — Sam, the casual power user
- **Age:** 19 · **Role:** College student
- **Stack:** YouTube, Reddit, recipe sites, random blogs
- **Daily:** Discovers 20+ "interesting" things. Saves 0.
- **Pain point:** *"I saw a pasta recipe last Friday. It had chili flakes."*
- **Aha moment:** "pasta with chili flakes recipe" → finds it in 2 seconds.
- **Key feature:** Natural language search for non-technical content.
